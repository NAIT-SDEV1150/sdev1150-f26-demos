How to hunt

This page has 8 bugs planted in it. Use DevTools (F12) to find each one. Fix one bug at a time, save, reload, and test again.

  1. Reproduce it: what did you do, what did you expect, what happened?
  2. Read the message in the Console (red = error, yellow = warning).
  3. Locate the line: click the file name on the right of the message.
  4. Guess the cause, then test the guess (log, breakpoint, Elements).
  5. Fix one thing, then re-test from a fresh reload.

Things to try: add two books, mark one as read, tick "Show unread only", click Save list, then reload. Check every panel: Console, Elements, Sources, Network, Application.
