Demo 18: HTTP, JSON and REST

This page came from the server you started with npm start. Open DevTools (F12), go to the Network tab, then click the links below.

1. Try GET requests in the browser

Typing a URL or clicking a link always sends a GET request. Each link opens the raw JSON the server sends back.

  • GET /api/books 200, a JSON array
  • GET /api/books/42 200, one JSON object
  • GET /api/books?available=true 200, query string filters the list
  • GET /api/books?q=the 200, search title or author
  • GET /api/books/999 404, no such book
  • GET /api/books/abc 400, bad id
  • GET /old-books 301, then the browser follows it
  • GET /api/broken 500, the server failed
  • GET /api/health 200, is the server up?

To send POST, PUT, PATCH or DELETE, use requests.http in VS Code (REST Client) or Thunder Client. A plain link can't.

2. JSON playground
