Every rule below is an HTML attribute. Click Sign up to see the browser check them.

type="email" required: must be filled in and look like an email
minlength="2" maxlength="20": 2 to 20 characters
type="number" min="13" max="120" step="1": a whole number from 13 to 120
pattern="…": must match the pattern; title="…" is added to the message
type="url" without required: empty is fine, but if typed it must be a URL
type="date" min max: a date in that range
select required: the empty first option doesn't count
