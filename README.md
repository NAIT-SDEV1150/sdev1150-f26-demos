## Get the demos

**Option 1: download a zip.** Click the green **Code** button above, then **Download ZIP**. Unzip it and open the folder in VS Code.

**Option 2: clone with Git** (recommended: you can pull new demos after each class):

```bash
git clone https://github.com/NAIT-SDEV1150/sdev1150-f26-demos.git
cd sdev1150-f26-demos
```

After each class, get the new demos with:

```bash
git pull
```

## Run a demo

Open the folder in VS Code, right-click a demo's `index.html` and choose **Open with Live Server**.
