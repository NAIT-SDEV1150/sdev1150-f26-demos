# SDEV 1150 · Class demos (Fall 2026)

Every demo from class, one folder each. New demos are added after each class.

| Folder | What it shows |
|---|---|
| `01-selectors` | `querySelector` and CSS selectors |
| `02-hover-swap` | Swapping content on hover |
| `03-todo-basic` | A to-do list: create and append elements |
| `04-todo-styled` | The to-do list, styled |
| `05-show-hide` | Showing and hiding with `classList` |
| `06-tic-tac-toe` | Events and game state |
| `07-input-events` | `input`, `focus`/`blur`, `change`, `keydown` |
| `08-login-form` | `submit`, `preventDefault`, validation messages |
| `09-template-cards` | `<template>` and `cloneNode` |
| `10-practice-dom-events` | 25-question practice set (`QUESTIONS.md`, `WALKTHROUGH.md`) |
| `11-selector-quest` | Selector Quest game (also on [KaktusLive Games](https://kaktuslive.dev/games)) |

## Get the demos

**Option 1: download a zip.** Click the green **Code** button above, then **Download ZIP**. Unzip it and open the folder in VS Code.

**Option 2: clone with Git** (recommended: you can pull new demos after each class):

```bash
git clone <this repository's URL>
cd sdev1150-f26-demos
```

After each class, get the new demos with:

```bash
git pull
```

## Run a demo

Open the folder in VS Code, right-click a demo's `index.html` and choose **Open with Live Server**.
